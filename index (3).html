Cómo sacar tu token (una sola vez)

1. Abre github.com/settings/personal-access-tokens/new
2. Nombre: portafolio. Expiración: la que quieras.
3. Repository access → Only select repositories → tu repo del portafolio.
4. Permissions → Repository permissions → Contents: Read and write.
5. Generate token, cópialo y pégalo arriba.

El token se guarda solo en este navegador, nunca dentro de tu página. No lo compartas con nadie.

Los cambios se ven al instante y se guardan en este navegador. Para que todos los vean, presiona Guardar en GitHub.
